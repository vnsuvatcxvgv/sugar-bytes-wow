## Overview

Sugar Bytes WOW is an expressive wah and filter plugin with envelope, LFO, and audio-follower-driven modulation modes, adding funky, responsive filter sweeps to guitar, synth, and vocals.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sugar Bytes WOW** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Auto Wah** | Envelope follower drives cutoff for touch-sensitive wah effects |
| **LFO Mode** | Tempo-synced LFO for rhythmic filter pulsing and trance effects |
| **Filter Types** | Low-pass, band-pass, high-pass, and vocal formant filter modes |
| **Resonance** | Wide resonance range from subtle musicality to screaming self-oscillation |
